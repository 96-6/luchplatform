# Адаптация навыков и повторения — задача 7

Адаптация использует сохранённые попытки luch engine. Второго проверяющего ответы нет: оценка, помощь и исходный ответ остаются в истории. Контент закреплён редакцией пакета; первоначальные причины и порядок плана не переписываются.

## Правила 1.0.0

| Сохранённый результат                                            | Изменение навыка                               | Следующее действие                                                  |
| ---------------------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------- |
| Ошибка                                                           | `needs_practice`, отдельный счётчик ошибок     | Дополнительное тренировочное упражнение на тот же навык             |
| Успех с подсказкой                                               | `supported`, счётчик успехов с подсказкой      | Практика для самостоятельного ответа                                |
| Успех после объяснения, повторной попытки или помощи суперадмина | `supported`, отдельный счётчик помощи          | Практика для самостоятельного ответа                                |
| Самостоятельный успех                                            | `demonstrated`, самостоятельные ответы и серия | Следующий доступный шаг маршрута и отсроченная контрольная проверка |
| Самостоятельный успех на назначенной отсроченной проверке        | `confirmed`                                    | Подтверждение в истории; новые проверки по кругу не создаются       |

Состояние относится к демонстрационным заданиям и не подтверждает общий уровень владения языком. Диагностические наблюдения считаются отдельно; их успех оставляет состояние `learning` до дальнейшей практики. Успех с подсказкой сохраняет исходный балл, но не приравнивается к самостоятельному ответу.

Дополнительное назначение содержит одно упражнение `practice`; выбирается другое задание того же навыка, если оно есть в закреплённом банке. Проверка использует отдельный банк `control`, без подсказок. В демо-банке для каждого навыка есть оба вида. Отсутствие нужного задания импортированного курса сохраняется в истории как отсутствие банка, без фиктивного задания.

Одно незавершённое назначение каждого дополнительного вида на навык используется повторно. Новая ошибка сохраняет собственное наблюдение и причину повторного использования, а очередь не заполняется одинаковыми заданиями. После завершения ошибочного корректирующего упражнения допускается новое назначение. Успех с помощью в корректирующей практике ведёт к отсроченной проверке, вместо бесконечного повторения помогавшего упражнения.

Срок проверки по умолчанию 48 часов. Администратор или суперадмин задаёт 24–336 часов для будущих назначений. Дата уже назначенного повторения сохраняется. До неё сервер и интерфейс запрещают обычный запуск. Суперадмин может открыть его раньше для отладки; это отмечается как помощь и не подтверждает самостоятельность.

`nextAssignmentId` сначала продолжает активное прохождение, затем выбирает готовую коррекцию, самостоятельную практику, наступившее повторение и шаги исходного плана. Будущие проверки видны с датой и выключенной кнопкой. Полностью завершённый план не показывается, пока есть незавершённые повторения.

## Хранение и восстановление

Миграция 009 добавляет `student_skill_states`, `skill_observations`, `learning_plan_changes`, виды назначений, дату доступности и закрытия, а также отдельные сгенерированные варианты. Каждое наблюдение связано с исходной попыткой; история изменения хранит дату, причину, навык, результат, назначение и автора действия.

Обычная тренировка обновляет навык и план вместе с сохранением попытки. Диагностика, контроль и отдельное адаптивное назначение обрабатываются после завершения прохождения. Это сохраняет закрытую оценку проверки и позволяет закрыть текущее корректирующее назначение до выбора следующего. Ошибка сохранения откатывает связанные изменения; повтор запроса использует тот же результат. Уникальные ограничения и транзакции защищают наблюдения, назначения и историю от повторной обработки.

При запуске API восстанавливает пригодные необработанные события. Незавершённые диагностические, контрольные и адаптивные прохождения продолжаются с сохранёнными ответами и не задерживают запуск. Старые события, созданные до установки адаптации, пополняют состояние навыков без назначения всей исторической практики заново.

Отдельная команда: `npm run learning:recover`. Она безопасна для повторного запуска. Для локального PGlite сначала остановить API; для собранного контейнера используется `node apps/api/dist/modules/adaptation/cli.js`. Не требуется ручная правка базы.

## Экран и доступ

`/plan/:id` показывает назначения, даты, причины, историю и навыки. Состояние навыков также доступно ученику, его преподавателю и суперадмину в карточке ученика. Чужие данные защищены серверной проверкой связи. Администратор настройки платных сервисов не получает доступ ко всем личным данным; этот доступ остаётся у суперадмина.

Необязательная генерация меняет только вариант дополнительного тренировочного задания. Проверки и исходный банк остаются закреплёнными. Настройка — [PROVIDERS.md](PROVIDERS.md), методы — [API.md](API.md), проверка — [ACCEPTANCE_TASK_7.md](ACCEPTANCE_TASK_7.md).
