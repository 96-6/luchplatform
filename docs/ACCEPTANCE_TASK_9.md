# Приёмка задачи 9 — аватары и текстовый помощник

Основание: задача 9 заказчика, дополнения о HeyGen и выдаче непросмотренного кэша, раздел 7 расширенного ТЗ ЛУЧ (11.09.2026). Задача 8 не включалась в работу по этому поручению.

**Статус: выполнена и проверена, 13 октября 2026.**

## Реализовано

| Пункт                 | Результат                                                                                          |
| --------------------- | -------------------------------------------------------------------------------------------------- |
| 9.1                   | Три собственных демонстрационных SVG-персонажа, экран выбора и простая отключаемая анимация        |
| 9.2                   | Выбор, голос, обращение, темп и подробность сохраняются в профиле аккаунта с защитой от конфликтов |
| 9.3                   | Сохраняемый чат упражнения, история страницами, автор и время каждого действия                     |

| 9.5                   | Объяснение, подсказка и тематический диалог; явная отметка «Демо-помощник»                         |

Для проверки обновления исходный код задачи 7 создал пользователя, прошёл диагностику и начал назначение с сохранённой подсказкой, ответом и черновиком следующего упражнения. Перед обновлением были зафиксированы количества старых сущностей. После запуска новой миграции они совпали; новая версия прочитала прежний черновик `Legacy saved draft`, позволила выбрать персонажа и записать чат без пересоздания аккаунта или плана.

Серверные проверки также подтвердили права/CSRF, идемпотентность сообщений, откат при ошибке записи, учёт помощи, передачу последней попытки при смене шага, запрет контрольных подсказок, работу непросмотренного банка/генерированного кэша, исчерпание кредита и отсутствие учебного штрафа за технический сбой. Для HeyGen проверены polling, удержание неопределённого резерва, контроль превышения, защищённый Range и повторное использование после отключения. Listening также использует подходящий сохранённый текст/язык при недоступном провайдере и смене голоса.

В первом контейнерном прогоне отсутствовал новый проверочный скрипт в runtime-образе. Dockerfile исправлен; полный повторный CI итогового кода прошёл. Предыдущие миграции, банк и проверки задач 1–7 сохранены.

## Границы

Текстовый помощник сценарный. Голосовой ответ ученика, STT и live-avatar streaming относятся к последующим задачам. Платные API проверяются тестовыми ответами, без реальных ключей/списаний. Возможность настоящего рендера подтверждается отдельно с ключом, поддерживаемым HeyGen look, голосом и тарифом аккаунта.

Инструкции — [ASSISTANT.md](ASSISTANT.md); обновление существующей установки: остановить API, выполнить `git pull`, `npm ci`, `npm run setup`, затем `npm run dev`.
