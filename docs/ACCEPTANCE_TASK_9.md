# Приёмка задачи 9 — аватары и текстовый помощник

Основание: задача 9 заказчика, дополнения о HeyGen и выдаче непросмотренного кэша, раздел 7 расширенного ТЗ ЛУЧ (11.09.2026). Задача 8 не включалась в работу по этому поручению.

## Реализовано

| Пункт                 | Результат                                                                                          |
| --------------------- | -------------------------------------------------------------------------------------------------- |
| 9.1                   | Три собственных демонстрационных SVG-персонажа, экран выбора и простая отключаемая анимация        |
| 9.2                   | Выбор, голос, обращение, темп и подробность сохраняются в профиле аккаунта с защитой от конфликтов |
| 9.3                   | Сохраняемый чат упражнения, история страницами, автор и время каждого действия                     |
| 9.4                   | Сервер собирает текущую закреплённую редакцию задания, попытку, её результат и учебный материал    |
| 9.5                   | Объяснение, подсказка и тематический диалог; явная отметка «Демо-помощник»                         |
| 9.6                   | Состояния ожидания/ошибки, безопасный повтор и серверная блокировка помощи в контроле/диагностике  |
| HeyGen                | Серверный v3-адаптер, настройки суперадмина, общие резервы/лимиты, защищённый MP4-кэш              |
| Недоступная генерация | Ещё не просмотренный подходящий кэш; при исчерпании — ошибка генерации без изменения оценки        |

Помощь учитывается существующим luch engine; новая версия не добавляет отдельного проверяющего ответы. Суперадмин видит переписку, сохранённый контекст и автора действий. Технические ошибки не создают учебные попытки. Предыдущие SQL-миграции и редакции банка сохранены.

## Проверки

Проверка типов и сборка выполняются локально. Серверный набор проверяет сохранение, оба языка, повтор сообщения, потерянный ответ, права владельца/преподавателя/суперадмина, CSRF, запрет контрольных подсказок, транзакционный откат, HeyGen polling/кэш/Range, отключение, лимиты, неопределённые сбои, исчерпание кредита и просмотренного банка.

Браузерные сценарии добавлены для выбора/повторного входа/мобильного экрана, ожидания и повтора потерянного ответа, контрольного режима, настройки HeyGen и воспроизведения сохранённого видео. GitHub Actions проверяет обычный PostgreSQL и Docker Compose с восстановлением аватара, чата, помощи и видео после перезапуска. Итоговые результаты CI записываются после выполнения.

## Границы

Текстовый помощник сценарный. Голосовой ответ ученика, STT и live-avatar streaming относятся к последующим задачам. Платные API проверяются тестовыми ответами, без реальных ключей/списаний. Возможность настоящего рендера подтверждается отдельно с ключом, поддерживаемым HeyGen look, голосом и тарифом аккаунта.

Инструкции — [ASSISTANT.md](ASSISTANT.md); обновление существующей установки: остановить API, выполнить `git pull`, `npm ci`, `npm run setup`, затем `npm run dev`.
