# Генерация, ElevenLabs и расходы

Дополнительные демонстрационные варианты создаёт серверный адаптер OpenAI или NeuroAPI. Озвучивание listening использует ElevenLabs. Без настроенных сервисов адаптация работает из учебного банка. Чат, запись микрофона и распознавание речи остаются следующими этапами.

## Подключение

1. Войти суперадмином и открыть «AI и расходы» (`/admin/providers`).
2. Задать общие денежные ограничения: за всё время, день, месяц и на ученика в день; число вызовов, размер ответа, объём озвучивания и одновременные запросы. Нулевой денежный предел блокирует платные обращения.
3. В выбранном провайдере сохранить ключ, совместимую модель и подтверждённые **верхние** цены своего тарифа. OpenAI/NeuroAPI — USD за миллион входных и выходных токенов; ElevenLabs — USD за тысячу символов. Для ElevenLabs также нужны разрешённые вашему аккаунту ID голосов для русского и английского.
4. Подтвердить актуальность цен и включить провайдера. При замене ключа, модели, голосов или цен через кабинет требуется новое подтверждение; при изменении ключа окружения подтвердите цены перед включением вручную. Цены не загружаются автоматически: тариф, скидки и пиковые надбавки различаются. Подтверждение действует в пределах заданного суперадмином срока, по умолчанию 24 часа.
5. В рабочих настройках включить генерацию и/или listening, установить допустимые текущие лимиты. Для аудиовариантов генерации включить также «Создавать listening-варианты».

Ключи можно задать через серверное окружение `OPENAI_API_KEY`, `NEUROAPI_API_KEY`, `ELEVENLABS_API_KEY`. Настройка в кабинете имеет приоритет; удаление ключа суперадмином отключает также запасной ключ из окружения для этого провайдера. Секреты не возвращаются в формы или журнал расходов. Не меняйте `AUTH_ENCRYPTION_KEY` без процедуры переноса сохранённых учётных данных.

| Возможность                                       | Администратор           | Суперадмин |
| ------------------------------------------------- | ----------------------- | ---------- |
| Включать адаптацию/listening и выбирать стратегию | Да, в пределах настроек | Да         |
| Рабочие бюджеты, число вызовов, размер ответов    | До общих ограничений    | Да         |
| Срок будущих повторений                           | Да                      | Да         |
| Просмотр агрегированных расходов и запросов       | Да                      | Да         |
| Общие пределы, модели, цены, голоса, ключи        | Нет                     | Да         |
| Все личные учебные данные и управление аккаунтами | Нет                     | Да         |

Роль `admin` создаётся суперадмином через готовый аккаунт. Обычная регистрация её не выдаёт. Кабинет `/operations` открывается после обычного входа почта + Authenticator.

## Выбор модели и сохранение

Стратегия `cheapest` сравнивает максимальную стоимость текущего запроса по указанным ценам среди включённых и доступных OpenAI/NeuroAPI. Она не утверждает, что один сервис всегда дешевле. Можно закрепить одного провайдера. Предлагаемая начальная текстовая модель — `gpt-4.1-mini`; выбранная модель должна поддерживать Chat Completions и строгий JSON Schema. Начальная модель ElevenLabs — `eleven_multilingual_v2`; совместимость, доступность модели/голоса и цену следует проверить своим аккаунтом.

Генерация вызывается при первом открытии коррекции или самостоятельной практики. Сервер передаёт учебный контекст, язык, навык и вид затруднения; исходные ответы и личные данные ученика не отправляются. Проверенный по структуре вариант получает собственный ID и демонстрационную маркировку. Он сохраняется отдельно от банка и проверяется обычным luch engine. Структурная проверка не заменяет педагогическую редактуру: фактический ответ модели может требовать проверки преподавателем.

Для listening контент содержит закрытый `listening.text`; ученический API показывает признак аудиозадания, без текста записи. Сервер ElevenLabs получает учебную реплику и язык. Аудио хранится в базе и выдаётся по защищённой ссылке прохождения, с поддержкой диапазонов для проигрывателя. Повтор открытия использует сохранённый вариант и аудио; технический сбой позволяет повторить подготовку и не меняет учебную оценку.

Сбой генерации, устаревшая цена, отсутствие ключа или недостаточный бюджет сохраняют доступное задание банка. Незавершённый сетевой вызов не повторяется автоматически с новым платёжным идентификатором. Для озвучивания отдельный явный повтор допустим в пределах лимитов.

## Учёт расходов

Денежные значения в API — целые микродоллары: 1 USD = 1 000 000. В кабинете используются USD. День и месяц считаются по UTC. Вызов допускается только после сохранения резерва по верхнему объёму и цене; успешный текстовый ответ уточняет сумму по сообщённым токенам. Неопределённый исход или прерывание сохраняет весь резерв. Превышение сообщённого объёма отключает платные вызовы до проверки настроек.

Расходы учитывают вызовы этого приложения и заданные оператором цены. Это не чтение реального баланса, налогов или полного счёта поставщика. Чтобы ограничить общий счёт, установите соответствующие пределы также в кабинете провайдера и используйте отдельный ключ проекта. Ошибочные тарифы или внешнее использование того же ключа не покрываются внутренним бюджетом.

Миграция 010 сохраняет настройки, провайдеры, запросы, резервы и аудиокэш. При параллельных API-процессах допуск сериализуется общей базой. Повторный запрос создания того же варианта не создаёт вторую оплату; аудио одного текста/модели/голоса использует общий кэш, сохраняя отдельный доступ через конкретный run.

Автотесты используют изолированные ключи и тестовые ответы провайдеров. Реальные платные вызовы не проверены без доступа к вашему тарифу; перед включением рабочего бюджета выполните небольшой пробный вызов и сверку счёта.
