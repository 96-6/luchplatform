# Проверка задачи 4 — luch engine

Дата: 12.10.2026. Исходные материалы — демо-пакет `luch-demo` v1 задачи 3. Критерий: ученик проходит урок, получает обратную связь и после повторного входа видит сохранённые результаты. Дополнение заказчика: суперадмин видит все данные движка; фоновые проверки честности включаются в этот же этап.

| Подзадача               | Реализация и фактическая проверка                                                                                                                  |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 4.1 Экран упражнения    | Материал и инструкция из закреплённой редакции; оба языка открыты и пройдены в браузере                                                            |
| 4.2 Ответ               | Выбор одного варианта и короткий текст; проверены неверный ответ, исправление, Unicode и сохранение исходной строки                                |
| 4.3 Проверка на сервере | luch engine использует решение и рубрику из базы; поддельный вариант/тип отклоняется без попытки                                                   |
| 4.4 Помощь и объяснение | Подсказка записывается однократно; в тренировке объяснение доступно после ответа; в закрытых банках результаты выдаются после завершения           |
| 4.5 Попытка             | Ответ, результат, автор, помощь, предыдущая обратная связь и два показателя времени сохраняются транзакционно                                      |
| 4.6 Продолжение         | Сохранить/выйти, выход из аккаунта, новый вход, восстановление черновика, следующий вопрос, завершение и обновление страницы                       |
| Доступ                  | Чужой ученик не читает и не меняет данные; преподаватель читает только закреплённых учеников; суперадмин видит всё и его действия сохраняют автора |
| Повтор доставки         | Конкурентные запросы, потерянный ответ сервера и повтор ключа не создают второй попытки и не пропускают шаг                                        |
| Версии                  | Начатое прохождение остаётся на v1 после публикации v2; новый цикл сохраняет историю                                                               |
| Фоновая проверка        | Контекст сохраняется и доступен проверяющим; переключатель суперадмина работает; учебный балл не изменяется                                        |
| Мобильный экран         | Контрольное задание пройдено на ширине 390 px без горизонтального переполнения                                                                     |

Локально выполнены проверка типов, 82 серверных теста (включая предыдущие этапы), сборка и 15 браузерных сценариев. Браузер проверяет оба языка, повторный вход, потерю ответа после записи в базе, доступ проверяющих и фоновые пометки. Проверены клавиатурный и сенсорный контексты, выключенная проверка, откат незавершённой транзакции и повторное открытие базы.

Миграции 004–005 применены к существующей локальной базе: техническая запись задачи 1 сохранилась, повтор загрузки контента вернул `unchanged`. Отдельные процессы `engine-smoke` сохранили ответ с подсказкой и незавершённый черновик, затем открыли базу снова и завершили урок с сохранённой историей.

Проверки обычного PostgreSQL и Docker Compose добавлены в GitHub Actions: тот же набор API-тестов и продолжение урока после перезапуска приложения. **Удалённый прогон для этого изменения ещё ожидается; эти проверки пока не отмечены как пройденные.**

Фоновая проверка даёт контекст для человека, а не гарантированное выявление нарушения. Ошибка получения наблюдений не создаёт неверный учебный ответ. Материалы остаются демонстрационными. Итог диагностики по навыкам, индивидуальный план и адаптация пока не реализованы. HTTPS-размещение и резервное восстановление относятся к задаче 14.

Задача 4 реализована и проверена локально; окончательная приёмка ожидает CI. Задача 5 не начата.
