# Проверка задачи 4 — luch engine

Дата: 12–13.10.2026. Исходные материалы — демо-пакет `luch-demo` v1 задачи 3. Критерий: ученик проходит урок, получает обратную связь и после повторного входа видит сохранённые результаты. Дополнение заказчика: суперадмин видит все данные движка; фоновые проверки честности включаются в этот же этап.

| Подзадача               | Реализация и фактическая проверка                                                                                                                  |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 4.1 Экран упражнения    | Материал и инструкция из закреплённой редакции; оба языка открыты и пройдены в браузере                                                            |
| 4.2 Ответ               | Выбор одного варианта и короткий текст; проверены неверный ответ, исправление, Unicode и сохранение исходной строки                                |
| 4.3 Проверка на сервере | luch engine использует решение и рубрику из базы; поддельный вариант/тип отклоняется без попытки                                                   |
| 4.4 Помощь и объяснение | Подсказка записывается однократно; в тренировке объяснение доступно после ответа; в закрытых банках результаты выдаются после завершения           |

| Мобильный экран         | Контрольное задание пройдено на ширине 390 px без горизонтального переполнения                                                                     |
