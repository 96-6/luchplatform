## Результат

Перед входом суперадмин выбирает «Войти в VANISH-режиме». По умолчанию выбран обычный вход. VANISH доступен в уже начавшемся звонке, в том числе при закрытом входе и включённом зале ожидания. Режим не запускает встречу и не меняет допуск других участников.

Скрытый зритель получает звук, камеры и демонстрации экрана, но отсутствует в плитках, списке присутствующих и счётчике остальных браузеров. Режим сохраняется в сессии PostgreSQL и восстанавливается при повторном выборе после обновления страницы. Смена режима требует выхода; одновременные видимое и скрытое подключения одного аккаунта исключены прежним уникальным ограничением базы.

Сервер разрешает VANISH только суперадмину и выдаёт скрытый допуск LiveKit только для подписки на медиа. Публикация камеры, микрофона, демонстрации, данных и собственной метаинформации запрещена. Поднятие руки, сообщения и загрузка вложений отклоняются API, чат доступен для чтения. Прежнее управление встречей остаётся доступно суперадмину с обычной атрибуцией действий; последствия модерации видны участникам. VANISH скрывает присутствие в комнате, а не административные действия или инфраструктурные журналы.

Вход и явный выход попадают в журнал действий. Сохранённая операция входа содержит встречу, режим и идентификатор подключения; повтор потерянного ответа не создаёт вторую сессию. Завершение встречи закрывает скрытые подключения. После утраты роли, деактивации или блокировки фоновая обработка отключает действующий VANISH; новые допуски и переподключения проверяют актуальную роль.

Миграция 023 добавляет только флаг с выключенным значением по умолчанию и ограничения для гостевой идентичности/руки. Прежние миграции, встречи, приглашения и учебные данные сохраняются. Обновление: остановить API, обновить `main`, выполнить `npm ci`, `npm run setup`, `npm run build` и запустить приложение.
