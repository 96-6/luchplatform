# Обновления платформы и диагностика из LAN

Запрос от 1 ноября 2026. Добавить суперадмину проверку установленной сборки относительно GitHub main, ручную и автоматическую проверку раз в шесть часов, красную точку, обновление с журналом и сохранением страницы. Диагностика сервера должна быть доступна авторизованному суперадмину с другого компьютера.

**Статус: реализация и приёмка продолжаются.**

Обновление выполняет отдельный управляемый процесс; исходники подготавливаются до остановки API. Перед миграцией нужна сохранённая копия базы, после переключения — проверка готовности; при ошибке восстанавливается прежняя версия. Конфигурация, сессии и пользовательские файлы сохраняются. Для Node предусмотрен управляемый запуск, для Compose — отдельный служебный контейнер без доступа к Docker socket. Публичное размещение задачи 14 не выполняется.

Результаты проверок будут внесены после фактического выполнения.
