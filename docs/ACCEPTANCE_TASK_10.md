## Проверки

Локально прошли типы, сборка и 19 новых серверных сценариев на PGlite. Полный регрессионный CI, обычный PostgreSQL и Docker проверяются перед завершением приёмки. Итоговые числа и ссылка на прогон будут записаны после фактического завершения.

Серверные сценарии охватывают WAV/длительность/тишину, multipart и язык RU/EN, отсутствие попытки до подтверждения, исходный/исправленный текст, выбор без угадывания, короткий текст, прежние подсказки и чужое участие, ошибки STT/TTS, явные повторы, закрытые оценки, блокировки одновременных подтверждений, атомарный откат, авторизацию/CSRF, лимиты/срок цены, прерывание и удаление просроченной записи, кэш и Range. Браузерные проверки используют настоящий путь AudioWorklet с синтетическим микрофоном и воспроизводимый MP3, а ответы ElevenLabs заменены тестовым адаптером.

`scripts/speech-smoke.mjs` включён в runtime Docker и CI до/после перезапуска. Он проверяет сохранение распознанных реплик, ошибок по обоим языкам, причин коррекции, незавершённого подтверждения, MP3 и учёта расходов; после перезапуска проверяет повтор без платного вызова и ветку самостоятельного успеха.

## Границы и запуск

Реального ключа ElevenLabs в этой проверке нет; платный запрос с вашим аккаунтом не выполнялся. Контракт проверялся по официальной документации ElevenLabs, интеграция — ответами тестового адаптера. По умолчанию STT/TTS выключены, бюджеты и предел записи нулевые. Для настоящего распознавания/озвучивания требуются серверный ключ, доступные вашему аккаунту модели/голоса, подтверждённые верхние цены и включённые лимиты. Настройка — [SPEECH.md](SPEECH.md).

Оценивается подтверждённое содержание реплики, а не фонетика. Переписка сохраняет отметку «Демо-помощник». Контроль и диагностика не раскрывают правильность/подсказку до завершения. Запись требует HTTPS/localhost и поддержки AudioWorklet; текстовая альтернатива доступна независимо от подключения ElevenLabs. Исчерпание непросмотренного демо-банка сохраняет прежнюю техническую ошибку генерации; это не учебный штраф.

Обновление: остановить API, выполнить `git pull`, `npm ci`, `npm run setup`; затем `npm run dev` либо `npm run build` и `npm start`. Для PostgreSQL/контейнера применить миграции перед запуском. Прежние аккаунты и учебные данные продолжают использоваться.
