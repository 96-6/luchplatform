# Интерфейсы, обслуживание и прямые ссылки

Отдельное поручение после задач 1–13, от 17 октября 2026. Повседневные учебные и административные действия доступны в браузере. Демобанк и сценарный помощник остаются обозначенными деморежимами с настоящим сохранением данных.

## Кабинеты и обслуживание

| Роль          | Возможности                                                                                                                                   |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Ученик        | Анкета, диагностика, план, упражнения, голос/помощник, занятия, домашняя работа, комментарии и отчёт                                          |
| Преподаватель | Закреплённые ученики, проверка ответов, комментарии и назначения, расписание/модерация/итог, отчёты                                           |
| Администратор | `/operations`: фактическая сводка и очереди, повтор обработки готовых событий/видеокоманд, расписание и AI в пределах ограничений суперадмина |
| Суперадмин    | Аккаунты/2FA, закрепление и снятие преподавателей, материалы, данные учеников, ключи/бюджеты, безопасность, журнал и обслуживание             |

Меню зависит от роли и прокручивается на компьютере/телефоне. Выход открывает страницу входа. Для планов, анкеты, помощника, комментариев и отчёта преподаватель/суперадмин находят и выбирают ученика в интерфейсе. Карточки служебных аккаунтов не предлагают переходы к учебному профилю. Персональные прохождения начинает ученик; сотрудники используют предварительный просмотр материалов, а суперадмин действует через план/прохождение выбранного ученика или отдельный собственный отладочный цикл.

Суперадмин снимает закрепление в карточке аккаунта. Прежние учебные ссылки и API преподавателя сразу закрываются; ответы, назначения и история сохраняются. Участие в старых видеозанятиях определяется составом конкретной встречи. Неиспользуемый `PlaceholderPage` удалён; пустые данные имеют отдельные состояния и доступные следующие действия.

`/operations` показывает реальные числа пользователей, материалов, занятий, готовых/отложенных событий, видеокоманд и технических ошибок. Ожидание завершения учеником не считается сбоем. Наличие настройки провайдера не означает его текущую доступность. Сводка не раскрывает ключи, адрес базы или ответы.

Администратор и суперадмин могут обработать до 50 готовых прохождений за действие и повторить готовые видеокоманды. Используются прежние обработчики и блокировки. При недоступном видеосервере очередь сохраняется. Платные обращения автоматически не повторяются.

Суперадмину также доступны повторяемая загрузка демобанка и очистка истёкших сырых аудиозаписей. Загрузка не создаёт аккаунты и не заменяет другие редакции; при конфликте используется импорт новой версии. Очистка сохраняет расшифровки, попытки, оценки и озвучивание обратной связи.

Операции сохраняют автора, дату и результат. Повтор с тем же идентификатором возвращает прежний результат; одновременные доставки не запускают второе действие. Прерванная операция остаётся в журнале, после неё можно запустить отдельное безопасное действие.

Прежние CLI-команды и серверная консоль через терминал/SSH сохранены. Они нужны для первичной установки, параметров базы/почты/видеосервера, первого суперадмина, миграций перед запуском, размещения и аварийного восстановления доступа. Обычная учебная работа, аккаунты, материалы, ключи провайдеров и готовые очереди управляются через кабинеты. Произвольные серверные команды из веб-страницы не выполняются.

## Ссылки и ресурсы

Одна политика применяется перед выдачей страницы и внутри SPA. API независимо проверяет данные и изменения. Проверяются формат пути и параметров, роль, владелец/закрепление, наличие объекта и временные условия. Дубликаты/неизвестные параметры отклоняются; внешние перенаправления через параметры страниц не принимаются.

| HTTP | Условия                                                                                       |
| ---- | --------------------------------------------------------------------------------------------- |
| 400  | Некорректная ссылка или параметры                                                             |
| 401  | Нет действующей сессии или временного допуска Authenticator                                   |
| 403  | Недостаточная роль или запрещённый вход во встречу                                            |
| 404  | Неизвестная страница, отсутствующий/чужой учебный объект, неизвестный файл                    |
| 410  | Недействительная/истёкшая/использованная ссылка подтверждения, завершённая/отменённая комната |

Чтение ссылки подтверждения не расходует её; расходует отдельное подтверждение. Authenticator требует действующую временную HttpOnly-cookie; адрес страницы её не заменяет. Секрет подключения в HTML не встраивается. Ссылки на собственные сохранённые уроки/планы продолжают работать после нового входа и не зависят от браузерных временных файлов.

Видеокомната проверяет блокировку участника, закрытие входа и состояние встречи. Прежние проверки подписанного допуска/медиа сохраняются. Карточка завершённого занятия остаётся доступна его участникам.

Статическая раздача ограничена ресурсами сборки, аватарами и модулем записи. `/learning-media/` требует входа, записи опубликованного банка и файла внутри разрешённого каталога. Неизвестные временные пути и прямой `/index.html` не открывают приложение. Личное аудио/видео остаётся за авторизованными API. Ошибки содержат безопасный текст/код обращения; страницы не кешируются и не передают временную ссылку через referrer.

Собранное приложение и `npm run dev` используют серверную проверку страниц. Vite проксирует учебные файлы через API. Файловый доступ разработческого сервера ограничен клиентом, собранными контрактами и зависимостями; канонические пути проверяются и после разрешения символических ссылок. Учебный банк, исходники API и параметры окружения через него не выдаются. Миграция **016** добавляет журнал операций; миграции 001–015 сохранены. Обновление — прежними командами установки/миграции.
