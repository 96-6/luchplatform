# Внеплановые видеовстречи, приглашения и вложения

Запрос от 26 октября 2026. Дополнение к выполненной задаче 12; задача 14 и публичное развёртывание не начаты.

**Статус: реализация подготовлена, окончательные проверки в процессе.**

## Результат

В расписании преподавателя добавлена отдельная кнопка «Внеплановая встреча». Настраиваются время начала, длительность или отсутствие ограничения, тип ссылки, срок действия приглашения и разрешение гостевого входа. Одноразовое приглашение закрепляется за первым участником и допускает его возвращение. По многоразовой ссылке организатор может создать следующую встречу с отдельной историей.

Гости входят по имени без создания обычной учётной записи, проходят зал ожидания и используют прежние видео, звук, руку и чат. Доступ ограничен своей встречей; учебные и административные методы недоступны. Организатор может удалить гостя, разрешить возврат, отозвать приглашение или запретить гостей.

Чат принимает файлы и изображения, до пяти вложений на сообщение. По умолчанию размер не больше 125 МБ, строго больше 50 МБ — срок 10 дней. Суперадмин меняет максимум, порог и срок в интерфейсе. Загрузка показывает состояние, отмену и повтор; чат сохраняет историю, изображения, ссылки и срок удаления. Истёкший файл сразу недоступен и удаляется фоновой обработкой с сохранением метаданных сообщения.

Миграция 019 сохраняет прежние встречи и учебные данные. Метаданные, гости, ссылки и сообщения хранятся в PostgreSQL, байты вложений — в отдельном постоянном томе. Сервер проверяет доступ, реальный размер, срок хранения и повторы; опасные активные форматы не показываются как страницы.

## Проверки

Локально пройдены `npm run typecheck` с каталогом переводов, `npm run build` и полный набор PGlite: 304 пройдено, 1 пропущен. Добавлено 17 серверных сценариев для ссылок, гостей, лимитов, истории, очистки, повторов и неопределённого результата фиксации файла.

Новые браузерные сценарии проверяют гостя с реальными медиа LiveKit, изображения/файлы, сохранение после обновления, новую встречу по прежней ссылке, вход через пароль/Authenticator, одноразовый доступ, английский мобильный экран, настройки суперадмина и повтор потерянной загрузки. Контейнерный сценарий проверяет восстановление приглашения, гостя, политики, сообщения и исходных байтов после перезапуска, затем удаление истёкшего файла. Эти проверки ещё не отмечены пройденными: результаты будут внесены после GitHub Actions.
