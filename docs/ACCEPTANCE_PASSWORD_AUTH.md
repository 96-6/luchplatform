# Авторизация по почте, паролю и отдельному второму фактору

Запрос от 21 октября 2026. Это дополнение к выполненным задачам 1–13; задача 14 не начата.

Реализованы регистрация с паролем, отдельный второй шаг Authenticator, восстановление и смена пароля, начальный пароль при создании пользователя и сброс суперадмином. Новые формы переведены на английский и включены в серверную проверку страниц. Пароли и хеши не выдаются через API. Суперадмин устанавливает и сбрасывает пароль; исходный пароль недоступен для просмотра.

Миграция 018 сохраняет пользователей, Authenticator и учебные данные, завершает прежние обычные сессии. Существующий пользователь устанавливает первый пароль через письмо или суперадмина. При восстановлении пароля второй фактор сохраняется. Настройка почты, серверного ключа и пользовательский путь описаны в README.

Проверены локально целевые API-сценарии новой схемы и переход с заполненной базы до миграции 018 с реальной учебной попыткой. Добавлены браузерные сценарии регистрации, второго шага после обновления страницы, восстановления, сброса суперадмином и английских форм на мобильном экране. Контейнерная проверка проверяет пароль и сессию после перезапуска.

Полный прогон и итоговые ссылки GitHub Actions будут записаны после выполнения проверок. Невыполненные проверки не считаются пройденными.
