# Подтверждение регистрации преподавателей

Самостоятельная регистрация с ролью «Преподаватель» требует одобрения суперадмина. Пользователь подтверждает почту и подключает Authenticator, затем видит сообщение «Регистрация преподавателя ожидает подтверждения суперадмином». До одобрения сессия преподавателя не выдаётся, кабинет, API и видеовстречи недоступны. При повторном входе после верного пароля отображается тот же статус ожидания.

Суперадмин открывает «Аккаунты пользователей», при необходимости включает «Только преподаватели, ожидающие подтверждения», открывает карточку и нажимает «Подтвердить регистрацию преподавателя». В карточке сохраняются имя и почта подтвердившего суперадмина и время; действие также доступно в журнале. Повторное нажатие не создаёт новое одобрение. Отказать можно существующей блокировкой с причиной или деактивацией.

После одобрения пользователь входит обычным паролем и кодом Authenticator. Подтверждение почты, 2FA, блокировка, деактивация и сетевые правила продолжают действовать. Ручной допуск браузера и отметка проверки сетевого доступа не заменяют одобрение регистрации. Обычный администратор и преподаватель не могут одобрять регистрации.

Уже существующие преподаватели сохраняют доступ. Создание преподавателя самим суперадмином или оператором не требует повторного одобрения. Регистрация ученика не меняется.

Перед запуском применить миграцию 026 через `npm run setup`. Изменение браузерного минимума до Chrome/Chromium 134 находится в миграции 025; она заменяет прежнее значение по умолчанию 154 и сохраняет другие установленные оператором пороги, списки и режимы.
