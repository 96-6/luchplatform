Добавлен защищённый `GET /api/v1/student/dashboard` и общий контракт ответа. Чтение не создаёт данные, не вызывает внешние сервисы и не раскрывает решения или закрытые оценки. Старые повторения не исчезают после новой диагностики. Новых миграций, зависимостей приложения и изменений прежних SQL-файлов нет.

## Проверки

11 новых серверных сценариев прошли на PGlite. Проверены оба языка, пустое состояние, вход и роли, запрет чужого селектора, часовые пояса/полночь/летнее время, отсутствие записи при чтении, продолжение самостоятельного урока и старой диагностики, ошибка/подсказка, граница срока повторения, повторение прежнего плана, скрытые результаты диагностики/контроля, смена цели/языка и отдельный учёт повторных попыток.

Сборка прошла. Полная регрессия, окончательные браузерные сценарии, проверка между процессами и CI выполняются. Результаты будут внесены после фактического завершения; этот статус не обозначает их как пройденные.

## Границы

Расписание и полный учебный отчёт открываются как явно обозначенные готовящиеся разделы; их реализация относится к задачам 12 и 13. Существующие помощник, история прохождений и краткий прогресс доступны. Учебные материалы и оценки остаются демонстрационными/предварительными. Техническая ошибка запуска не создаёт учебную попытку.

Обновление: остановить API, выполнить `git pull`, `npm ci`, `npm run setup`, затем `npm run dev`. Для собранного запуска дополнительно выполнить `npm run build` перед `npm start`. Правила и точки интеграции — [DASHBOARD.md](DASHBOARD.md), метод — [API.md](API.md).
