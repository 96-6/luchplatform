Серверные сценарии проверили оба языка, пустое состояние, вход и роли, запрет чужого селектора, часовые пояса/полночь/летнее время, отсутствие записи при чтении, продолжение самостоятельного урока и старой диагностики, ошибку/подсказку, точную границу срока повторения, повторение прежнего плана, скрытые результаты диагностики/контроля, смену цели/языка и отдельный учёт повторных попыток. Эти же 11 новых сценариев ранее отдельно прошли локально на PGlite.

Браузерные сценарии обоих языков начинают анкету и диагностику с главной, открывают назначение, сохраняют ошибочный ответ и черновик следующего шага, выходят и входят снова, продолжают тот же run, завершают урок и проверяют обновлённые прогресс, коррекцию и будущую проверку. Пройдены переходы к плану, помощнику, расписанию и отчёту с обновлением вложенных страниц. Отдельно проверены ожидание, пустое состояние, некорректный ответ API и повтор после ошибки. Потерянный ответ успешного запуска повторён: нового прохождения или учебного штрафа нет.

Контейнерный `scripts/plan-smoke.mjs` подтвердил чтение главной до и после перезапуска API на обычном PostgreSQL. После завершения назначенного урока главная показала 1 завершённый урок, фактическое выполнение плана, последние ответы и отсроченное повторение. Сохранены предыдущие проверки помощника, адаптации, платных адаптеров с тестовыми ответами, аудио/видеокэша и контента. Прежние миграции и зависимости приложения не изменены.

В первом параллельном локальном прогоне возникли таймауты подготовки/перезапуска PGlite и загрузки браузера. Приёмка подтверждена полным CI со штатными таймаутами репозитория; ограничения проверок в коде ради прохождения не увеличивались. Локальные языковые сценарии также прошли по отдельности. Обычный PostgreSQL и Docker проверялись в CI.

## Границы

Расписание и полный учебный отчёт открываются как явно обозначенные готовящиеся разделы; их реализация относится к задачам 12 и 13. Существующие помощник, история прохождений и краткий прогресс доступны. Учебные материалы и оценки остаются демонстрационными/предварительными. Техническая ошибка запуска не создаёт учебную попытку.

Обновление: остановить API, выполнить `git pull`, `npm ci`, `npm run setup`, затем `npm run dev`. Для собранного запуска дополнительно выполнить `npm run build` перед `npm start`. Правила и точки интеграции — [DASHBOARD.md](DASHBOARD.md), метод — [API.md](API.md).
