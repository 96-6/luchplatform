# Проверка задачи 1

Этот протокол фиксирует проверку технической основы, а не полного учебного сценария. Дата выполнения: 12.10.2026. Время исполнения среды может отличаться от часового пояса заказчика.

## Проверки

| Проверка                    | Действия                                                  | Результат                                                                                                                                                                        |
| --------------------------- | --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Установка                   | `npm install`, затем `npm ci` по закреплённому lock-файлу | Зависимости установлены                                                                                                                                                          |
| Типы                        | `npm run typecheck`                                       | Пройдено                                                                                                                                                                         |
| Структура базы              | `npm run setup`; повтор `db:migrate`                      | Первая миграция применена; повтор не дублирует структуру                                                                                                                         |
| Сохранение в новом процессе | `db:smoke`, затем `db:verify-smoke`                       | Одна и та же запись прочитана после закрытия первого процесса                                                                                                                    |
| API и миграции              | `npm test`                                                | 26 проверок пройдены: сохранение, повторные/параллельные запросы, конфликт, валидация, транзакция, сбой, readiness, отключение dev API, сохранение на диск и блокировка каталога |
| Сборка                      | `npm run build`                                           | Клиент и сервер собраны                                                                                                                                                          |
| Браузер                     | `npm run test:e2e`                                        | 6 проверок пройдены локально и в GitHub Actions: запись/обновление страницы, загрузка, ошибка/повтор, формат ответа API, вложенные страницы и мобильная навигация                |
| Обычный PostgreSQL          | Тот же набор API-проверок с `TEST_DATABASE_URL`           | Пройдено в GitHub Actions на PostgreSQL 17: все 26 проверок                                                                                                                      |
| Docker Compose              | Сборка, готовность, запись и чтение после перезапуска     | Пройдено в GitHub Actions: образ собран, приложение готово, запись прочитана после перезапуска контейнера; локально Docker отсутствует                                           |

Локальный браузер: headless Chromium 153 через `PLAYWRIGHT_EXECUTABLE_PATH` (скачивание стандартного браузера Playwright недоступно в этой среде). В GitHub Actions используется штатный Chromium Playwright. Во время проверки исправлено открытие корневого SPA-маршрута; повторный полный браузерный прогон пройден.

Полный [прогон GitHub Actions](https://github.com/96-6/luchplatform/actions/runs/38308250932) завершён успешно для коммита `445f49fc00227d7591586d6284b7e6f416a6c8fa`. Пройдены установка из lock-файла, форматирование, типы, оба драйвера PostgreSQL, сборка, штатный Chromium и контейнерный сценарий.

Дополнительно локально запущен именно `npm run dev` из README: браузер открыл клиент через Vite, запросы прошли через proxy, тестовая запись сохранилась и осталась после обновления. Десктопный и мобильный интерфейсы осмотрены по снимкам.

**Задача 1 выполнена:** приложение запускается по инструкции, открывается в браузере и сохраняет запись в базе. Задача 2 ещё не начата.
